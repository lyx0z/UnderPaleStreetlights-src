# Under Pale Streetlights

A short visual novel made with [Ren'Py](https://www.renpy.org/) 8.3.6.

Anya gets into a new city, and joins a band. The city is super creepy for some reason...

## Play
Download the latest build from the [Releases](../../releases) page.

## Run from source
1. Install the [Ren'Py SDK](https://www.renpy.org/latest.html) (8.3.x).
2. Clone or download this repo into your Ren'Py projects directory.
3. Open the Ren'Py launcher, select the project, and click **Launch Project**.
